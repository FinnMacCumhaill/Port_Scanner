# Port_Scanner
I developed an advanced multthreading Port Scanner, that always is a handy tool, that is helpful and it can be applied to a variety of use cases, everything from conducting a security assessment or even for auditing purposes, by Penetration Testers, Red Teamers, Incident Responsers, SOC Analysts across both Offensive and Defensive Security.
This is also useful for administrators and engineers, especially roles like Network Admins, Sysadmins, Security Engineers, Network Engineers, System Engineers, and even IT Support Engineers.

##CLI Port Scanner tool

----------------------------------------------------------------------------------------------------------------------------------------
The user will be prompted to enter the set of parameters, in order to successfully conduct the port scan of their chosen target/network.
These parameters are the target/network, the starting port, and finally the end port.
Note: Start and end port parameters are used to determine your port number range, e.g. 1-1000, 1000-10000 and so on.
---------------------------------------------------------------------------------------------------------------------------------------
python port_scanner.py

Enter your target ip: [Target\Network IP Address]
Enter the start port: [Starting Port Number]
Enter end port: [Last Port Number]

###Starts the Scanning Process
Starting scan on host: [Target\Network IP Address]
Progress: [Iterate through each port until, we reach the total number of ports] /total_ports scanned
