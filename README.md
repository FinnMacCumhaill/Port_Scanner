# Port_Scanner
I developed a Port Scanner, that always handy tool that is helpful and has a variety of use cases, everything from security assessment or auditing purposes, by Penetration Testers, Red Teamers, Incident Responsers, SOC Analysts across both Offensive and Defensive Security.
This is also useful for administrators and engineers, especially roles like Network Admins, Sysadmins, Security Engineers, Network Engineers, System Engineers, and even IT Support Engineers.
